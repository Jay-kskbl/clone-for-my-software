## 1. 逐文件修改记录

### 1.1 `frontend/src/components/ExtractedText.vue`（新增，135 行）

从 `PreviewView.vue` **原样搬过来**的 Word/Excel 文本列表，没有改行为：

| 搬过来的部分 | 说明 |
|---|---|
| `loadText()` | 调 `getDocumentText`，每页 50 个，可带 `chunk_id` 跳页；出错时弹 `ElMessage` |
| `scrollToTarget()` | `nextTick` + 两次 `requestAnimationFrame` 后 `scrollIntoView`，注释原样保留 |
| `onTextPageChange()` | 翻页 |
| 模板 | 提示条、空状态、片段列表（定位说明、OCR 标注、`highlightText` 高亮）、分页 |
| 样式 | `.notice`、`.chunk`、`.chunk.target`、`.chunk-meta`、`.chunk-text`、`em`、`.pagination` |

和原来相比改了两处：

| # | 原来 | 现在 | 原因 |
|---|---|---|---|
| 1 | 提示文字、空状态文字写死在 PreviewView 里 | 改为属性 `notice`、`emptyText` 传入 | Word/Excel 和 PDF/图片要显示不同的文字 |
| 2 | 由 PreviewView 在 `load()` 里调用 `loadText` 和 `scrollToTarget` | 组件在 `onMounted` 里自己调用 | 放进懒加载的标签页后，第一次切过去才挂载，就是按需加载 |

属性：`documentId`、`targetChunk`、`terms`、`notice`、`emptyText`。

### 1.3 `frontend/src/utils/preview.ts`（新增，17 行）

`initialPreviewTab(kind, query)`：

| 条件 | 结果 |
|---|---|
| `query.view` 是 `'file'` 或 `'text'` | 照它 |
| 图片，且 `query.chunk` 是非空字符串（从检索结果打开） | `'text'` |
| 其他（包括从检索结果打开 PDF） | `'file'` |

写成纯函数，是为了不用组件测试工具也能单测。

### 1.4 `frontend/tests/preview.test.ts`（新增，5 项）

| 测试 | 验证什么 |
|---|---|

## 3. 修改建议（后续）

1. **补看一次滚动。** 把浏览器面板显示出来（或在自己的浏览器里），打开一个 Word 检索结果和一个图片检索结果，确认会滚到命中的片段。这一步只需要看，不用改代码。
2. **扫描 PDF 的 OCR 命中。** 现在仍默认打开原文件、跳到那一页，原图上看不到高亮。如果演示时觉得不方便，可以按方案里的可选项改成默认打开“抽取文本”，只需改 `initialPreviewTab` 一处（要多传命中片段的 `source_type`）。
3. **答辩演示脚本（T32）。** 可以加一步：搜一个只出现在图片里的词 → 打开结果 → 直接看到 OCR 识别出的文字和高亮 → 切到“原文件”对照原图。
