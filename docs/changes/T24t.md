## 1. 问题

T24m 的测试 `frontend/tests/pdfjs-assets.test.mjs` 逐个比较 `frontend/public/pdfjs/` 和 `node_modules/pdfjs-dist` 里文件的 sha256。这个目录有 202 个文件，其中 15 个是文本文件（LICENSE、`.js`）。在 Windows 上，git 设了 `core.autocrlf=true` 时，这 15 个文件签出时会变成 CRLF，sha256 对不上，测试失败，但代码其实没问题。W5 第 11.2 节原来只写了检查办法和临时处理，根治办法留给 Barry 决定。

## 3. 验证（macOS，git 2.50.1，没有安装任何东西）

在 scratchpad 里模拟 Windows 签出：`git clone --no-checkout -c core.autocrlf=true <本仓库> clone`，用 sparse-checkout（`--no-cone`）只签出 `frontend/public/pdfjs/`，另签出 `frontend/README.md` 作对照。clone 里没有 `.gitattributes`（当时还没提交）。sha256 都和主仓库工作区里的同名文件比较。

| 组 | 做法 | `git ls-files --eol`（pdfjs 目录） | sha256 与主仓库一致 |
|---|---|---|---|
| 对照组 | 直接签出 | 187 个 `i/-text w/-text attr/`，**15 个 `i/lf w/crlf attr/`** | 187 / 202 |
| 实验组 | 把主仓库的 `.gitattributes` 复制到 clone 根目录，删掉 `frontend/public/pdfjs` 后重新签出 | 187 个 `i/-text w/-text attr/-text`，15 个 `i/lf w/lf attr/-text` | **202 / 202** |

- 对照文件 `frontend/README.md` 在两组里都是 `i/lf w/crlf`：规则只作用于 pdfjs 目录，模拟签出确实生效。
- **补充实验：已经签出成 CRLF 的工作区。** 先恢复成对照组的状态（15 个 `w/crlf`），再放进 `.gitattributes`、不重新签出：`git status` 把这 15 个文件显示为已修改（` M`），文件仍是 CRLF。在 clone 里执行 `git checkout -- frontend/public/pdfjs` 后，变成 `w/lf`，`git status` 不再显示修改。所以 Windows 上已有的工作区拉到 T24t 后，要重新签出这个目录一次（见第 4 节第 1 条）。
- 主仓库：`git ls-files --eol -- frontend/public/pdfjs` 为 187 个 `i/-text w/-text attr/-text` 和 15 个 `i/lf w/lf attr/-text`；`git status --short` 只有新的 `.gitattributes` 和根目录两个 .docx，pdfjs 下没有文件显示为已修改。
- 在 `frontend/` 下运行 `npm test -- tests/pdfjs-assets.test.mjs`：1 个文件、3 项通过。
- 验证完已删除 scratchpad 里的 clone。
- **未测试（Not Tested）**：真实 Windows 机器上的签出，仍按 W5 第 11.2 节执行。

## 4. 修改建议（后续）

1. 真正的 Windows 核对仍按 `windows任务书.md` W5 第 11.2 节执行。如果那台机器的工作区在 T24t 之前就签出了（文件已是 CRLF），拉取后这 15 个文件会显示为已修改，要在仓库根目录执行一次 `git checkout -- frontend/public/pdfjs`。执行前先确认这个目录没有别的改动，再跑 `git ls-files --eol` 和 `npm test -- tests/pdfjs-assets.test.mjs`。这一点已报给主会话，由它转给负责改任务书的会话。
2. 以后若有别的按字节比对的目录（例如复制进仓库、由测试逐字节核对的第三方资源），也照此在 `.gitattributes` 里单独加一条 `-text`，不要改全仓库的换行策略。
3. 这个目录里的文件不要手工编辑；要更新就用 `npm run sync:pdfjs`（T24m）。有了 `-text`，git 不会再替这些文件转换换行符。
