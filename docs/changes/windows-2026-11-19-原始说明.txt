二、8 个 WinError 1314 失败
---------------------------

backend（6 项）：
  tests/unit/test_consistency.py::test_symlinks_are_never_treated_as_stored_files
  tests/unit/test_storage.py::test_file_symlink_pointing_outside_rejected
  tests/unit/test_storage.py::test_directory_symlink_pointing_outside_rejected[year]
  tests/unit/test_storage.py::test_directory_symlink_pointing_outside_rejected[document]
  tests/unit/test_storage.py::test_put_refuses_to_write_through_directory_symlink
  tests/unit/test_storage.py::test_symlinked_temp_directory_refused_at_startup

shared（2 项）：
  tests/test_storage_keys.py::test_symlinked_directory_is_rejected
  tests/test_storage_keys.py::test_symlinked_file_is_rejected

失败位置：
  测试准备阶段调用 os.symlink 或 Path.symlink_to，尚未进入项目业务代码。

错误：
  OSError: [WinError 1314] 客户端没有所需的特权。

解决方法：
  1. 打开 Windows“设置 → 系统 → 开发者选项 → 开发人员模式”。
  2. 注销并重新登录或重启。
  3. 在 Barry 的普通用户终端（不是 CodexSandboxOffline）运行 whoami /priv。
  4. 确认出现 SeCreateSymbolicLinkPrivilege。
  5. 重跑 backend 和 shared 测试。

也可以在具有 SeCreateSymbolicLinkPrivilege 的管理员终端中运行。
不能把测试改成 junction：这些测试专门验证符号链接逃逸，junction 不能替代。


三、已修复并复测通过
--------------------

1. 中文 PDF 原文件预览空白
   原因：PDF.js 没有配置 CMap、标准字体、WASM 和 ICC 静态资源。
   修复：PdfViewer 配置对应的资源地址，资源放入 frontend/public/pdfjs。
   复测：真实中文 PDF 正常显示；前端 67 项、类型检查和生产构建通过。

2. psycopg 异常类名断言
   原失败：测试写死 OperationalError，实际为更具体子类 ConnectionTimeout。
   修复：断言只要求安全的异常类名，并继续检查不得泄漏连接信息。
   复测：相关 backend 单元测试通过。

3. OpenSearch 余弦分数断言
   原失败：测试写死完全相同向量必须得 2.0，OpenSearch 2.19.1 实际为 1.0。
   修复：保留真正重要且跨版本稳定的断言：排序正确、严格递减。
   复测：真实 OpenSearch 向量测试 8 项全部通过。
