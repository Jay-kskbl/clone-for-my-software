## 1. 问题

OCR 参数或模型不一致时（D42、D46 会拦下），唯一的办法是在空库上重新 import 并处理。阶段五比较不同 DPI、置信度阈值时，每组参数都要整库重来。重新解析也不行：`parse_version` 不变，不会再建 OCR 任务。
