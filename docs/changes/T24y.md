## 1. 问题（C1，在 main 的代码上核对过）

登录、注册出错时只在页面顶部弹一条 `ElMessage`，约 3 秒就消失，离表单远，还盖在系统标志上，用户容易看漏原因；演示截图里也看不到。另外后端的说明比较笼统：用户名已存在只说“用户名已存在”，参数不合格给出 Pydantic 的原始描述（“请求参数不合法：body.username: String should …”），普通用户不知道下一步怎么做。

## 2. 修改

| 文件 | 修改 | 原因与影响 |
|---|---|---|
| `frontend/src/features/login/errors.ts`（新增） | `LOGIN_ERROR_TEXT`：5 个错误码的说明——`INVALID_CREDENTIALS` 用户名或密码错误；`USERNAME_TAKEN` 这个用户名已被注册。换一个用户名，或切换到登录；`VALIDATION_ERROR` 用户名或密码不符合要求：用户名 3–32 个字符，密码 8–128 个字符；`DATABASE_UNAVAILABLE` 数据库暂时不可用，请稍后再试；`INTERNAL_ERROR` 服务器内部错误，请稍后再试。`loginErrorText(error)`：`ApiError` 查表，查不到显示后端原文；不是 `ApiError` 时用 `errorMessage` 的通用说明 | 用 `Map` 而不是普通对象，未知错误码（例如恰好叫 `constructor`）不会取到原型上的属性。前端自己生成的错误（连不上服务器、开发代理 502、无法识别的应答）本来就是中文说明，原样显示。分支上这里还负责中英文切换，main 不需要，只留中文 |
| `frontend/src/features/login/LoginForm.vue` | “登录”按钮上方加 `el-alert`（自带 `role="alert"`）：登录 / 注册失败为红色，“账号已创建，但自动登录没有成功（原因）……”为黄色；用户修改用户名或密码、切换登录 / 注册、重新提交时收起。“注册成功，已自动登录”仍用顶部提示 | 修 C1。成功提示留在顶部：页面马上跳走，表单内的提示看不到。分支上提示保存的是错误对象（切换语言后文字跟着变），main 没有语言切换，直接保存文字 |
| `frontend/tests/login/errors.test.ts`（新增，12 项） | 5 个错误码各显示登录页自己的说明；参数不合格时不显示 `body.username` 这类原文；没列出的错误码显示后端原文；错误码叫 `constructor` 时仍显示原文；网络不通、502、无法识别的应答原样显示；不是 `ApiError` 时显示“发生了未预期的错误” | 按 main 改写：分支上的用例主要测中英文两套文字 |

## 3. 验证

- `npm run typecheck` 通过；`npm test` 15 个文件 189 项通过（新增 12 项）；`npm run build` 成功。
- 浏览器检查（开发服务器 + 临时模拟后端，1280×800）：
  - 密码错误：按钮上方红色提示“用户名或密码错误”，4 秒后仍在，`role="alert"`，页面顶部没有弹出提示；在密码框里多输一个字符，提示收起；
  - 注册模式下用已存在的用户名：提示“这个用户名已被注册。换一个用户名，或切换到登录”；切回登录模式，提示收起；
  - 模拟后端返回 502（后端没启动）时点“登录”：提示“服务暂时不可用（HTTP 502），请确认后端已启动”；
  - 注册后的第一次登录返回 503：切回登录模式，黄色提示“账号已创建，但自动登录没有成功（数据库暂时不可用，请稍后再试）。已切换到登录，请再点一次“登录”。”，用户名保留。
