C11  services/ocr_worker/ocr_worker/engine_process.py（第 147、184 行）
----------------------------------------------------------------------
类型：生产代码 / Windows 子进程时序
原因：子进程崩溃时，父进程先收到管道 EOF，再读取 process.exitcode。
      在 Windows 上此时进程可能尚未完全退出，exitcode 为 None，
      错误信息变成“退出码 None”，测试无法确认崩溃码 3。
      应先等待子进程结束（join）再读取退出码。

修改位置 1（第 147 行，启动阶段 EOF）：
修改前：
  except EOFError:
      exitcode = process.exitcode
      self._stop()

修改后：
  except EOFError:
      process.join(_KILL_WAIT_SECONDS)
      exitcode = process.exitcode
      self._stop()

修改位置 2（第 184 行，识别阶段 EOF）：
修改前：
  except EOFError:
      exitcode = self._process.exitcode
      self._stop()

修改后：
  except EOFError:
      self._process.join(_KILL_WAIT_SECONDS)
      exitcode = self._process.exitcode
      self._stop()

C13  backend/tests/unit/test_health.py、test_worker_main.py

验证：相关 backend 单元测试通过。
