一、逐文件修改记录
------------------

1. 新增 scripts/datasets/docvqa_import.py

   - 用 httpx 调 datasets-server rows 接口，每批 100 行。
   - 立即下载当批签名图片，地址过期时刷新该批 rows。
   - 纯函数负责编号、排序、文本清洗、文件头识别、manifest/queries/qrels 转换。
   - file_id = dv_ + image_filename；query_id = dvq_ + questionId。
   - PNG/JPEG 按文件头判断，其它格式报错；单图上限 50 MB。
   - 记录 sha256、字节数、宽、高。
   - source_rows.jsonl 不保存签名地址。
   - 已有图片在 sha256 一致时跳过；网络失败最多重试 3 次。

2. 新增 scripts/datasets/tests/test_docvqa_import.py

   - 12 项测试，全部使用假数据和假网络对象。
   - 覆盖编号与排序、重复查询共用图片、PNG/JPEG/其它文件头、
     制表符和换行清洗、CSV 逗号和引号、load_dataset 回读、
     已有 sha256 一致时不再下载、签名地址不写入留底。

3. 新增 scripts/__init__.py、scripts/datasets/__init__.py

   - 让测试可通过 scripts.datasets.docvqa_import 稳定导入。

4. 修改 .gitignore
